## ✨ Core Features

*   **Role-Based Access Control (RBAC):** Secure login with distinct permissions for Admins and standard users.
*   **Real-time Dashboard:** Visual analytics and summary metrics.
*   **CRUD Operations:** Seamlessly create, read, update, and delete records via a RESTful API.
*   **Responsive UI:** Mobile-friendly frontend built with modern design principles.

## 🛠️ Tech Stack

**Frontend:**
*   React.js / Next.js
*   Tailwind CSS / HTML / CSS
*   Axios for API calls

**Backend:**
*   Java / Spring Boot
*   Spring Security & JWT Authentication
*   Hibernate / JPA

**Database & Tools:**
*   MySQL

*   Postman (API Testing)

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
*   Node.js & npm installed
*   Java Development Kit (JDK 17+) installed
*   MySQL Server running locally

### 1. Database Setup
1. Open MySQL Workbench or your preferred database client.
2. Create a new database named `pmis_db`.
3. The tables will be auto-generated by Hibernate when the backend starts.

## 🚀 Getting Started

### Prerequisites

Install a Java Development Kit (JDK) and configure Java on your system.

Verify the installation:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/pratikgodase07/PMIS.git
cd PMIS
```

### Compile and Run a Java Program

1. Navigate to the folder containing the Java source file.
2. Compile the program:

   ```bash
   javac YourClass.java
   ```

3. Run the compiled class:

   ```bash
   java YourClass
   ```

Replace `YourClass` with the actual class name. Ensure the filename matches the public class name and follow the appropriate package structure, if applicable.
