## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Git
- A Java-compatible IDE, such as Eclipse or IntelliJ IDEA, or a text editor

Verify your Java installation:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/pratikgodase07/PMIS.git
cd PMIS
```

### Compile and Run a Java Program

Navigate to the directory containing the Java source file and execute:

```bash
javac Example.java
java Example
```

Replace `Example` with the actual filename and class name. These commands apply to simple Java programs without package declarations or external dependencies.

## My Practice Approach

For each exercise, my goal is to:

1. Understand the problem statement.
2. Identify the logic and possible solution.
3. Implement the solution in Java.
4. Compile and run the program.
5. Test different inputs and debug errors.
6. Review the code and improve it where necessary.

This approach helps turn theoretical knowledge into practical programming skills.

## Version Control

Git and GitHub help me track my progress and maintain a history of my practice work.

```bash

git commit -m "Add Java practice exercises"
git push origin main
```

Before committing, I review the changed files and avoid committing generated `.class` files or unrelated files.
