## 📖 Overview

**PMIS** is a day-by-day log of my Java internship: core Java and OOP, concurrency, generics and lambdas, testing, JDBC, a Spring Boot REST API, a hackathon team project, and algorithm practice.

It isn't one big application. Every folder is a **self-contained topic or day**, so you can open any one and run it on its own.

## 🚀 Getting Started

> [!NOTE]
> You need **JDK 17+** and **Git**. Maven is optional, because the Spring projects include a Maven wrapper.

```bash
java -version
git clone https://github.com/pratikgodase07/PMIS.git
cd PMIS
```

<details open>
<summary><b>▶️ Run a single-file exercise</b></summary>

<br/>

```bash
cd "Basic Excercise"
javac Exercise_1.java
java Exercise_1
```

Works for files with no `package` line and no external dependencies. Files inside packages should be compiled from their source root.

</details>

<details>
<summary><b>🌱 Run a Spring Boot project</b></summary>

<br/>

```bash
cd November_2nd/Smart-Campus-EV-Shuttle-Tracker---Group-1
./mvnw spring-boot:run     # Windows: mvnw.cmd spring-boot:run
./mvnw test                # run the unit tests
```

The shuttle tracker uses MySQL and can fall back to an embedded H2 database. Configuration, architecture, and business rules are in its [own README](November_2nd/Smart-Campus-EV-Shuttle-Tracker---Group-1/README.md). `october_29th/studentAPI/studentAPI` runs the same way.

</details>
