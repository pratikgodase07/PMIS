## ✨ Core Features

*   **Role-Based Access Control (RBAC):** Secure login with distinct permissions for Admins and standard users.
*   **Real-time Dashboard:** Visual analytics and summary metrics.
*   **CRUD Operations:** Seamlessly create, read, update, and delete records via a RESTful API.
*   **Responsive UI:** Mobile-friendly frontend built with modern design principles.

## 🛠️ Tech Stack

**Frontend:**
*   React.js / Next.js
*   Tailwind CSS / HTML / CSS
*   Axios for API calls

**Backend:**
*   Java / Spring Boot
*   Spring Security & JWT Authentication
*   Hibernate / JPA

**Database & Tools:**
*   MySQL
*   Git & GitHub
*   Postman (API Testing)

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
*   Node.js & npm installed
*   Java Development Kit (JDK 17+) installed
*   MySQL Server running locally

### 1. Database Setup
1. Open MySQL Workbench or your preferred database client.
2. Create a new database named `pmis_db`.
3. The tables will be auto-generated by Hibernate when the backend starts.

### 2. Backend Setup
```bash
# Clone the repository
git clone [https://github.com/pratikgodase07/PMIS.git](https://github.com/pratikgodase07/PMIS.git)

# Navigate to the backend directory
cd PMIS/backend

# Configure database credentials
# Open src/main/resources/application.properties and update:
# spring.datasource.username=your_username
# spring.datasource.password=your_password

# Run the Spring Boot application
mvn spring-boot:run
