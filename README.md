## Overview

**PMIS** is a software development repository dedicated to Java programming, practical implementation, and continuous improvement of software development skills.

The repository serves as a central workspace for organizing source code, exploring programming concepts, practising implementation techniques, and maintaining development progress through version control.

The goal is to build a strong foundation in Java while following good software development practices, including readable code, structured documentation, maintainability, and incremental improvements.

## Objectives

- **Strengthen Java fundamentals:** Develop a deeper understanding of Java syntax, language features, and programming principles.
- **Apply object-oriented programming:** Practise class design, encapsulation, inheritance, polymorphism, and abstraction where applicable.
- **Improve problem-solving:** Translate programming requirements into clear, maintainable solutions.
- **Maintain code quality:** Follow consistent naming conventions, readable formatting, and meaningful documentation.
- **Use version control effectively:** Track changes, maintain a development history, and use Git and GitHub for source code management.
- **Support continuous learning:** Expand the repository as new concepts, exercises, and project requirements are explored.

## Getting Started

### Prerequisites

Install a compatible Java Development Kit (JDK) and Git.

Verify the installations:

```bash
java -version
javac -version
git --version
```

### Clone the Repository

```bash
git clone https://github.com/pratikgodase07/PMIS.git
cd PMIS
```

### Compile and Execute a Java Program

Navigate to the directory containing the Java source file.

```bash
javac Example.java
java Example
```

Replace `Example` with the actual Java filename and class name. These commands apply to simple programs without package declarations or external dependencies.

## Development Workflow

This repository uses Git for tracking changes and GitHub for remote source code management.

```bash
# Review local changes
git status

# Stage selected changes
git add README.md

# Commit with a meaningful message
git commit -m "Improve project documentation"

# Push changes to GitHub
git push origin main
```

Use descriptive commit messages and review staged files before committing.

## Code Quality Principles

The project aims to follow these development principles as it evolves:

- Write code that is readable and easy to understand.
- Use meaningful class, method, and variable names.
- Keep methods focused on specific responsibilities.
- Avoid unnecessary duplication.
- Document important design decisions and non-obvious logic.
- Exclude generated build artifacts and environment-specific files from version control.
- Make incremental changes that are easy to review.

## Contribution and Maintenance

For personal development, the repository can be updated incrementally as new concepts and project work are completed.

Before sharing changes:

1. Review the modified files.
2. Test relevant Java programs.
3. Confirm that generated files and sensitive information are excluded.
4. Write a descriptive commit message.
5. Push the verified changes to GitHub.
