## ⚡ Quick Start

```bash
# 1️⃣ Create the database
mysql -u root -p -e "CREATE DATABASE psg;"

# 2️⃣ Run a Spring Boot project
cd db_springboot/demo/demo
./mvnw spring-boot:run        # → http://localhost:8080
```

**Try it:** `POST /StudentAPI/addStudentData` with a JSON `Student` body 🎓

> 🛠️ Needs **JDK 17+**, **Maven**, **MySQL 8**. Update DB credentials in each project's config before running, and never commit real passwords. 🔐
